揭秘 sm_89、sm_86 与 sm_75：为什么 CUDA 代码在 RTX 40/30 系列上报错？如何确认代号？

1. 缘起

我在配置机器学习环境的时候，遇到了这个报错：

原来是CUDA和NVIDIA显卡不兼容的问题。

那么，如果我想要使用这个版本的CUDA（项目依赖指定必须如此），那么，我应该如何去反推我要租赁的显卡型号呢？在中文互联网寻找一圈，发现有一些不错的帖子，但不是很完全，后来我发现了如何找到完全版本列表的方法，今天分享在这里

2. 解决方法：

访问这两个官方链接，即可找到对照表：

  • https://developer.nvidia.com/cuda/gpus
  • https://developer.nvidia.com/cuda/gpus/legacy

我把截图贴在下方，方便查看：

需要特别注意的是小数版本号和sm版本号转换逻辑：

  • Compute Capability 12.1 => sm_121
  • Compute Capability 7.2 => sm_72
  • sm_37 => Compute Capability 3.7

关键就是把小数去掉即可！
